## 🚀 실행 방법
 
### 1. 레포지토리 clone
```bash
git clone https://github.com/Pirogramming-25/Piro25_PythonGame_1.git
cd Piro25_PythonGame_1
```
 
### 2. 실행
```bash
python3 main.py
```
 
### 3. 진행 순서
1. 게임 진행 여부(y/n) 입력
2. 이름 입력
3. 본인 주량(1~5) 선택 → 치사량 결정
4. 함께할 친구 인원수(1~3명) 선택 → 컴퓨터가 랜덤으로 이름/주량 배정
5. 참가자들이 순서대로 게임을 선택하며 진행
   - 내 턴: 직접 게임 번호 선택
   - 컴퓨터 턴: 자동으로 게임 선택 및 진행
6. 게임 결과에 따라 벌주 반영, 상태(마신 잔 수 / 치사량까지 남은 잔 수) 출력
7. 누군가 치사량에 도달하면 게임 종료

## 🎮 미니게임 규칙 설명
 
### 1. 시장에 가면 (서영은)
1. 게임을 시작하면 순서대로 한 사람씩 돌아가면서 물건을 하나씩 추가해서 말한다.
(단, 미리 정해진 시장 물건 목록 안에 있는 단어여야 하며, 목록에 없는 단어를 말하면 실패 처리된다.)
2. 본인 차례가 되면, 지금까지 나온 물건들을 순서대로 전부 기억해서 입력하고 마지막에 새 물건 하나를 추가해야 한다.
3. 입력할 때 단어는 반드시 띄어쓰기로만 구분한다.
4. 화면은 매 턴마다 지워지기 때문에 이전 내용을 스크롤로 다시 볼 수 없다. 오직 순간적으로 봤던 것만 기억해서 입력해야 한다.
5. 다음 조건 중 하나라도 해당하면 실패(벌칙) 처리된다:
 - 순서를 잘못 기억해서 틀리게 입력한 경우
 - 이미 나온 물건을 중복으로 다시 말한 경우
 - 시장 물건 목록에 없는 단어를 말한 경우
 - '포기'를 입력한 경우
6. 실패한 사람이 나오면 그 즉시 게임이 끝나고, 그 사람이 벌칙 대상이 된다.

### 2. 폭탄 돌리기 (임현아)
1. 게임을 시작하면 순서대로 한 사람씩 돌아가면서 폭탄을 받게 된다.
2. 폭탄을 받으면 랜덤으로 선택되는 질문에 5글자 이상 대답을 입력해야 다음 사람으로 넘어 간다.
3. 게임 시간 60~180초로 랜덤 설정 된다. (설정 후 별도로 알려주지 않는다.)
4. 10%의 확률로 special 질문 3개 중 하나가 나온다. (시간이 2배 빠르게 흐름/질문 없이 다음 사람으로 패스/3초 안에 아무 숫자나 입력하기)
5. 매번 답변에 소요된 시간을 언급해준다.
6. 랜덤으로 설정된 시간이 지난 후에도 폭탄을 가지고 있는 사람이 당첨된다.

### 3. 김밥말이 (이환희)
1. 게임을 시작한 사람에게 "김밥이 몇 줄?" 질문에  n(줄)이라고 답을 한다. (숫자 n을 스스로 정함, 1~전체인원-1 까지)
2. 현재 턴 다음 사람부터 n번째 사람까지 순서대로 "김밥말아!"를 외친다.
3. 사용자 차례가 오면, 미리 받아둔 반응("김밥말아" / 침묵)으로 정답 여부 판정
(내 차례인데 침묵하거나, 내 차례 아닌데 외치면 실수 처리)
+. 컴퓨터 참가자들도 각자 확률적으로 스스로 실수하기도 함
4. 실수한 사람이 한 명이라도 나오면 그 즉시 게임 종료 → 벌주행
5. 아무도 실수 안 하면 (n+1)번째 사람이 다음 라운드의 새로운 진행자가 되어 계속 반복한다.

### 4. 배스킨라빈스 31 (정승현)
1. 게임을 시작하면 순서대로 한 사람씩 돌아가면서 1~3개씩 숫자를 이어서 센다.
2. 직전 사람이 부른 개수(1개/2개/3개)는 다음 사람이 다시 부를 수 없다. (전략적으로 개수를 골라야 함)
3. 31을 부르는 사람이 벌칙 대상이 된다.
   
### 5. 지하철 게임 (신은아)
1.게임이 시작되면 1호선부터 9호선 중 하나의 지하철 노선이 무작위로 선택된다.
2. 순서대로 한 사람씩 선택된 노선의 지하철역 이름을 하나씩 입력해야 한다.
3. 플레이어(나)의 차례가 되면 7초의 제한 시간이 주어진다. 7초 이내에 입력하지 못하면 시간 초과로 즉시 실패한다.
4. 다음 조건 중 하나라도 해당하면 즉시 실패 처리된다.
- 제한 시간(7초)을 초과한 경우 (플레이어)
- 지정된 지하철 노선에 없는 역 이름을 말한 경우
- 이미 다른 사람이 앞에서 말한 역 이름을 중복으로 말한 경우
- 컴퓨터가 틀린 경우
5. 누군가 한 명이라도 실패하는 즉시 게임이 종료되고 패배자가 결정된다. (모든 턴이 무사히 넘어가면 공동 생존한다.)

## 🌿 Git Branch 전략

* **`main`** : 최종 완성본 브랜치 (**⚠️ 직접 커밋 절대 금지**)
* **`feature/성포함이니셜`** : 각자 기능을 작업하는 개인 브랜치
  * *예시:* `feature/sye` (서영은), `feature/lha` (임현아)
* **작업 흐름:** 개인 브랜치에서 작업 완료 ➔ GitHub에 Push ➔ **Pull Request(PR)** 생성 ➔ 팀원 리뷰 후 `main`으로 Merge

## 💬 Commit Message Convention

> **형식:** `타입: 내용`

* **`feat`**: 새로운 기능/섹션 구현
  * *예시:* `feat: 시장에 가면 게임 실제 로직 구현`
* **`fix`**: 코드 버그 및 예외 처리 오류 수정
  * *예시:* `fix: 지하철 게임 인덱스 바운드 에러 수정`
* **`style`**: 코드 포맷팅, 단순 줄바꿈, 텍스트 출력 문구 수정 (로직 변경 없음)
  * *예시:* `style: 게임 오버 아스키 아트 문구 수정`
* **`docs`**: 문서 수정 및 업데이트
  * *예시:* `docs: README 역할 분담 표 업데이트`

## 🛠️ 게임 함수 구현 가이드

### 📥 인자 (매개변수) 규칙
* `names` (list) : 참가자들의 이름이 담긴 문자열 리스트 (예: `['환희', '은아', '승현']`)
* `turn_idx` (int) : 현재 게임을 선택하여 시작한(선공) 사람의 index 번호

### 📤 리턴값 규칙
* `losers` (list) : 게임에서 패배하여 술을 마셔야 하는 사람들의 이름 리스트 (str 타입의 요소)
* **주의:** 패배자는 0명(공동 생존), 1명(독박), 혹은 여러 명(동시 탈락)일 수 있으므로 **반드시 리스트 형식**으로 반환해야 합니다. 아무도 안 걸렸을 때는 빈 리스트 `[]`를 반환합니다.
